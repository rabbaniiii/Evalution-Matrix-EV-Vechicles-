# 🚗 EV Price Prediction

This project uses **Machine Learning** to predict the price of Electric Vehicles (EVs) based on their driving range.

## 📌 About

The project uses **Linear Regression** to study the relationship between:

* **Range** — EV driving range
* **Price** — EV price

The goal is to predict the price of an EV based on its range.

## 🤖 Machine Learning Model

**Linear Regression**

The dataset is split into:

* 80% Training Data
* 20% Testing Data

## 📊 Model Evaluation

The model is evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

The project also includes an **Actual vs Predicted Price** visualization.
